## What's new in v1.0.1

- **Flash from your browser.** Chrome or Edge can now flash this release straight from the web: see "Flash from your browser" below, or the [README](https://github.com/M0LTE/quansheng-packet#flash-from-your-browser-chrome-or-edge) for the link that always loads the latest release.
- **The first start is a factory reset.** After flashing over any other firmware the radio no longer takes anything over from it (its frequency, TX band plan or S-meter settings). It starts on 144.800 MHz, low power, wide, with every setting at its default, writes those to its own settings area once, and remembers your changes from then on. The factory calibration is kept, as always.
- **A fixed transmit range.** The radio transmits only on 136 to 174 MHz and 400 to 470 MHz, the ranges its amplifier and filters are designed for, whatever another firmware had set up. Anywhere else a PTT press is refused, as before. Receive works across the whole range, now including 350 to 400 MHz.

**Upgrading from v1.0.0 resets your settings once.** v1.0.0 marked its settings in a way this release no longer trusts, so the first start after the upgrade puts everything back to the defaults above. Set your frequency, power and any other changes again (from the keypad and menu, or with `k5ctl -p PORT set ... --persist`); they stick from then on.

For software: GET_INFO now reports the TX band policy as 8 (fixed) with byte 36 reserved, and the settings layout as 2. The EEPROM layout is in `docs/packet-fw.md`, the protocol changes in `docs/protocol-v2.md`.
